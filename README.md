# 📦 Ecommerce Sales Analysis Dashboard


## 🎯 Objective

The purpose of this project is to build an interactive **Ecommerce Sales Analysis Dashboard** using Microsoft Excel. This dashboard consolidates and visualizes ecommerce performance data to assist businesses in tracking key performance indicators (KPIs), evaluating product category trends, and making informed decisions. It is designed for use by sales analysts, ecommerce managers, and stakeholders who need an at-a-glance overview of business performance.

---

## 🧠 Domain Knowledge: Ecommerce Analytics

**Ecommerce analytics** refers to the process of gathering, analyzing, and interpreting data from online business transactions. This enables businesses to:

- Understand customer behavior
- Monitor sales and profitability
- Identify high-performing regions and categories
- Enhance strategic decision-making

The dashboard focuses on the following key areas:

- **Sales Revenue**: Total sales generated over the period.
- **Profit**: Net earnings after costs.
- **Quantity Sold**: Total number of products sold.
- **Number of Orders**: Represents customer transactions.
- **Profit Margin**: Profit as a percentage of sales.
- **Category Analysis**: Performance breakdown by product category.
- **Subcategory Performance**: Top-performing subcategories by sales.
- **Geographical Sales**: Sales distribution across U.S. states.
- **Filter Options**: Segment data by Year, Segment, and Region.

---

## 💻 Requirements

To view or interact with this dashboard, ensure the following:

- Microsoft Excel 2016 or later (with PowerPivot and Power Query support)
- Basic understanding of Excel charts, slicers, and pivot tables
- A machine with moderate processing power for smoother experience

---

## 🚀 Usage

1. Clone or download this repository.
2. Open the Excel file (`Ecommerce_Sales_Dashboard.xlsx`) in Microsoft Excel.
3. Use slicers to filter data by:
   - **Year** (2011–2014)
   - **Customer Segment** (Consumer, Corporate, Home Office)
   - **Region** (Central, East, South, West)
4. Analyze KPIs and graphs to draw insights into business performance.
